# ITE 387: Advanced Programming Coding Standards

When developing or modifying code for ITE 387 assignments and projects, adhere strictly to the following academic principles:

## 1. JavaScript Foundations & Modularity
- **ES Modules (ESM):** Structure JavaScript into focused modules (`utilities.js`, `dom.js`, `data.js`, `main.js`) using standard `import` and `export`.
- **Arrow Functions:** Use arrow functions (`const fn = () => {}`) for callbacks, event handlers, and utilities.
- **Safe Initialization:** Always wrap DOM startup routines inside `DOMContentLoaded` or a `safeInit()` helper.
- **Single Source of Truth:** Store data in structured arrays and objects. Use `.map()`, `.filter()`, and `.reduce()` for transformations. Never mutate data structures in place.

## 2. DOM & UI Manipulation
- **4-Step Element Creation Lifecycle:** When generating DOM elements, follow:
  1. *Create:* `document.createElement(tag)`
  2. *Configure:* Set properties, text, CSS classes (`classList.add()`), or data attributes
  3. *Listen:* Attach event listeners directly (`addEventListener`)
  4. *Append:* Insert into parent node (`appendChild`)
- **Abstracted Helpers:** Use an abstracted helper (e.g., `create()`) to streamline multi-element hierarchy creation without raw HTML string concatenation.
- **Reusable Modal Shells:** Use a single programmatic modal shell rather than duplicating hidden modal markup across the document.

## 3. State Management & Form Handling
- **Consolidated Form State:** Store multi-field form data in a single unified object with default values, updating properties immutably using the spread operator (`...`).
- **User Feedback:** Provide clear, non-intrusive feedback via toasts or inline alerts following submissions.
